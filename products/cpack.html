CPACK 구성 및 특징

  • 01강력한 다축 모션제어기 기능 제공
  • 02PC기반 모션제어 SW 통해 최저비용으로 고성능 제어기능 제공
  • 03고객의 응용 프로그램을 구동하기 위하여 추가적인 HW 불필요 (고객의 PC에서 구현한 GUI로 운용 가능)
  • 04PLC 내장되어 별도의 IO카드가 불필요함
  • 05범용 C 언어로 Windows기반의 Host 프로그래밍 가능하며, 이를 지원하는 강력한 API를 제공
  • 06자체 리얼타임 시스템을 내장하고 있어, 빠르고 정확한 동작을 수행
  • 07최적의 가격으로 최고의 성능과 최적의 확장성을 제공

CPACK 응용 사례

APPLICATION 01

CPACK 응용 Ⅰ : 자동화 공정라인 적용 예

  • OLED 공정 장비의 제어기로 활용 가능
  • 비젼 얼라인 및 검사 기능 프로그램 가능
  • 각 스테이지당 축수 확장 6축 단위, IO 확장 32/32 단위로 확장 가능
APPLICATION 02

CPACK 응용 Ⅱ : 글라스 연삭장비 멀티 스테이지

  • Multi-stage로 배분하여 생산성을 향상 시키기 위한 구성
  • 소재 얼라인 Vision 적용
  • 최대 32축 완전 동기/보간 제어
  • 최대 1024 IO 접점 제공함
  • 공유메모리 직접 접근하여 고속 Host 제어기 TCP/IP 통신 지원
  • Windows기반의 Host 프로그래밍을 위한 API 제공
APPLICATION 03

CPACK 응용 Ⅲ : 비접촉 X-ray 박막 두께측정기 제어 시스템

  • FPCB 자재 Prealign - Loading - 측정 Stage - Unloading 일괄처리 자동화 장비
  • 비젼 얼라인 및 비접촉 X-ray 검사 시스템과 연동 가능
  • Dual 화면으로 비젼 얼라인/측정 검사 진행상황을 한 눈에 볼 수 있음
  • 총 6축 서보, 5 stepping 모터, 64/64 IO
